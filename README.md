# Swornim Global Delicacies

Single-page menu site with cart + WhatsApp ordering.

## Cart (v1)

- Add items from menu
- Edit quantity (+ / −) and remove in bottom cart bar
- Running total for priced items
- Send via WhatsApp with item list, qty, and total

## Dev

```bash
npm install
npm run dev
```

Update WhatsApp number in `src/data/menu.ts` (`WHATSAPP_NUMBER`).
